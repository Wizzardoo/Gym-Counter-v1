# Gym-Counter-v1
This is a small esp32 project for a table display to count your gym visits and work as a little table HUD.

### Features:
- time and date display
- a counter/tracker for gym visits (work in progress)
- weather display (work in progress)
- up to 6 alarms, repeating and non-repeating (work in progress)

### Requirements:
- WiFi connection
- USB-C connection to the esp32 for power

The device features some basic displaying functions such as time, current date and days of the week and current weather. The device also displays a counter for gym visits, but it's just a counter and can be used to track any other activities (you'll just need to change that in code)(will add a chapter later on for this). There's a function to set up alarms, up to 6 maximum.

## Navigation
There is a total of three buttons:  ```Next``` brings you to the next screen or changes the value, ```Confirm``` either expands the selected option of enters the edit mode, and ```Reset``` brings you to the previous screen.
